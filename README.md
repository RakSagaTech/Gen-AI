# 🚀 AI Interview & Resume Analyzer

This project is a full-stack AI-powered platform that helps users upload resumes, analyze job descriptions, detect skill gaps, and generate AI-powered interview questions and ATS-optimized resumes.

It is designed as a real-world SaaS-style application combining Full Stack Development with Generative AI features.

---

## ✨ Features

- 📄 Upload and analyze resumes  
- 💼 Job description skill matching  
- 🧠 AI-powered interview question generation  
- 📊 Skill gap analysis  
- 📝 ATS-optimized resume suggestions  
- 🔐 User authentication (Register/Login)  

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- bcrypt.js
- CORS & Cookies

### AI Integration
- Generative AI APIs (Gemini / OpenAI)

---

## 🌐 Deployment

- Frontend: Vercel  
- Backend: Render  
- Database: MongoDB Atlas
